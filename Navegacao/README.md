# Socialy - Tela de Navegação

Projeto mobile desenvolvido em **React Native** com **Expo** e **TypeScript**, reproduzindo a tela de navegação principal do aplicativo com fidelidade ao design original.

## 📱 Funcionalidades da Tela
- **Cabeçalho**: Botão de voltar e título centralizado "Navegação".
- **Descrição**: Texto explicativo da navegação na barra inferior.
- **5 Cartões Informativos**:
  - 🏠 **Início**: Feed de publicações
  - 🔍 **Buscar**: Procurar pessoas e conteúdo
  - ➕ **Criar**: Criar nova publicação
  - 🔔 **Notificações**: Ver interações e atividades
  - 👤 **Perfil**: Visualizar e editar perfil
- **Barra de Navegação Inferior**:
  - Abas interativas com ícones correspondentes
  - Botão de ação central destacado (+) para criação

---

## 🚀 Como Executar

### 1. Visualização Imediata (Navegador)
Basta dar um duplo clique no arquivo **`preview.html`** ou abri-lo no seu navegador favorito (Chrome, Edge, etc.) para ver a tela interativa com moldura de smartphone.

### 2. Executar no Expo (Mobile / Emulador)
```bash
# Instalar dependências (caso ainda não tenha instalado)
npm install

# Iniciar o servidor Expo
npx expo start
```
- Pressione `a` para abrir no emulador Android
- Pressione `w` para abrir no navegador web
- Ou escaneie o QR code com o app **Expo Go** no celular
